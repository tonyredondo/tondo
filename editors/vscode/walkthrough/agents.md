# Let agents write Tondo

VS Code's agents get the tools of `tondo mcp` without any setup: `check`,
`fix`, `run`, `test`, `debug_start`, `reload` and the rest.

For Claude Code and Codex, `tondo setup` registers the same server and
writes the Tondo skill, which teaches them the language. Start a new
session of the agent after it.

`tondo guide` is where the language is taught, to agents and to people.
