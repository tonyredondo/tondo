# Native link execution contract

`NATIVE-LINK-001` turns the hash-only link-plan records into a bounded physical
invocation. `NativeTargetDescriptor`, `NativeArtifact` and `NativeLinkPlan`
must validate against one another before any file is opened. The orchestrator
then resolves each logical input from an explicitly supplied bundle, verifies
its SHA-256, checks finite limits and invokes the exact driver executable with
an argument vector. It invokes the driver without shell expansion and never scans
PATH or the current directory for a substitute tool.

The output is first written to a workspace-local staging path, checked for the
declared object format, size and hash, and only then made visible to the caller.
Physical paths are orchestration inputs and are not serialized into the plan,
artifact identity or product receipt. A missing input, stale hash, directory or
symlink at the output, non-positive limit, driver mismatch or non-zero driver
exit fails before publication and leaves no partial product.

## Reproducibility

The contract test links the same small native fixture in two fresh workspace
directories with the same explicit driver and `--build-id=none` policy. It
compares product SHA-256 values and rejects any path or workspace bytes that
enter the identity. This is a physical smoke test of the closed invocation;
the typed plan/artifact tests continue to cover all record-level negatives.

Evidence is generated by [`scripts/native-link-test.sh`](../../scripts/native-link-test.sh)
under `target/reliability/evidence/native-link.json`. `NATIVE-CLI-001` consumes
this executor and adds the public `tondo build`/`tondo run` lifecycle.
