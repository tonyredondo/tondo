# Core implementation coordination for `std.0.1A`

`STD-IMPL-001` coordinates the seven Core owners and the shared serialization
kernel. Its reproducible register is `testing/stdlib-implementation-coordination.json`,
generated by `scripts/stdlib-implementation-coordination-generate.sh`.

Each owner retains its implementation paths, tests, component evidence and
`IMPL/HOST` matrix state. Public admission also requires a nonempty signature
inventory, every signature verified, and an owner audit without missing routes.
An empty callable inventory remains an explicit gap, including for a build-only
protocol. A Rust kernel or a documented trait cannot waive that gap.

The coordinator derives `closed-coordination` only when all eight owners meet
those conditions; otherwise it records `open-gaps`. The current serialization
inventory keeps Core coordination open. The global public API status is copied
from its own audit and is independent of the bounded Core component evidence.

```text
scripts/stdlib-implementation-coordination-check.sh
scripts/stdlib-implementation-coordination-test.sh
```

The checker validates current register consistency. Passing with `open-gaps`
does not close the tracker task, S1A, public conformance or native AOT. The tests
first accept the current baseline, then reject modified output and verify that
missing owners, empty signatures and missing implementation routes in generator
inputs cannot produce a closed coordinator.
