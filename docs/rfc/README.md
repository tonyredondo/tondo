# RFCs de Tondo

Esta carpeta contiene propuestas de diseño que todavía no son ADR aceptados.
Una RFC puede fijar una dirección de planificación, contratos y gates sin
afirmar que la implementación exista. Cuando una propuesta cierre una decisión
arquitectónica del baseline, se promoverá a un ADR nuevo sin reescribir el
historial.

|---|---|---|
