# why it can take no value a region makes anywhere. A test,
# crates/tondo/tests/regions.rs, holds this list to those of the compiler.

# library that keep them, as `http.Client.request`, an archive's writer or

# runs is run by the toolchain's own tests, named from the repository's
# root, as crates/tondo/tests/testing.rs, which run `tondo` with the check.
